**Aurel for Mac** is an AI that runs entirely on your Mac — it writes, researches, does math, builds documents and web pages, and listens to you. Your conversations and memory never leave the Mac. With the **Aurel app** on your phone you give it tasks on the go and follow every step.

> This repository contains **no source code**. It only hosts the download.

## Requirements

- Mac with **Apple silicon** (M1 or newer)
- at least **16 GB** of memory
- about **10 GB** of free space (model, speech recognition, runtime)
- **Python is included** in the download — nothing else to install
- the **Aurel app** with your account ([aurel-ly.com](https://aurel-ly.com))

## Install &amp; unlock

1. Download **[Aurel-for-Mac.zip](https://github.com/5s4frff94z-cyber/aurel-for-mac/releases/latest)** and double-click to unzip it.
2. Open the folder and double-click **“LIMA starten.command”**.
3. Read and accept the licence and privacy notice. On first start it sets itself up and downloads the model (≈ 6 GB); the Terminal window shows the progress.
4. Scan the QR code with your phone and type the comparison code — the one shown on your phone — into the Mac.
5. In the **Aurel app**, tap the **unlock** button and confirm with **Face ID**.
6. It opens in your browser. From now on a double-click is enough — **even offline**.

Up to **2 Macs** can be unlocked per Aurel account.

## If macOS blocks the first start

The app is not signed by a company, so on the first double-click macOS says the developer could not be verified. To open it anyway:

**System Settings → Privacy &amp; Security →** scroll down **→ Open Anyway** next to “LIMA starten.command”, then confirm once more. If macOS asks whether Terminal may access the folder, allow it.

## Privacy

Everything is computed on your Mac. Only the unlock stores an identifier of this Mac with Aurel and checks in every few weeks to see whether it is still valid — details in the [privacy policy](https://aurel-ly.com/rechtliches/datenschutz).
